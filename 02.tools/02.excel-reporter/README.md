# 📊 Excel Bug Reporter

버그 데이터 CSV 파일을 입력하면
자동으로 전문적인 엑셀 리포트를 생성하는 도구입니다.

---

## 📁 구조
```
02.excel-reporter/
├── bugs.csv        # 입력 데이터
├── reporter.py     # 핵심 모듈
├── main.py         # 실행 파일
├── README.md
└── 결과/
└── report_YYYY-MM-DD.xlsx
```

---

## ⚙️ 설치

```bash
pip install pandas openpyxl
```

---

## 🚀 실행

```bash
# 기본 실행
python main.py

# 파일 지정
python main.py bugs.csv
```

---

## 📊 리포트 구성

| 시트 | 내용 |
|------|------|
| 전체 버그 목록 | 심각도별 색상 구분 전체 목록 |
| 담당자별 현황 | 담당자별 버그 현황 + 차트 |
| 심각도별 통계 | Critical/Major/Minor 집계 |
| 요약 대시보드 | 해결률 등 핵심 지표 요약 |

---

## 🛠️ 기술 스택

| 기술 | 용도 |
|------|------|
| `pandas` | CSV 읽기 및 데이터 분석 |
| `openpyxl` | 엑셀 생성 및 스타일 |
| `pathlib` | 경로 관리 |
| `datetime` | 날짜별 파일명 |
